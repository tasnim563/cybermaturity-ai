CyberMaturity AI aide une organisation à mesurer son niveau de maturité en cybersécurité. L’utilisateur évalue 18 contrôles sur une échelle de 0 à 4. Le moteur de scoring en déduit un score par fonction NIST CSF 2.0 et un score global, puis classe les écarts par impact. Pour chaque écart prioritaire, le module RAG interroge un index FAISS construit à partir des documents NIST et ISO 27001. Il en tire des recommandations de remédiation avec leurs sources, rédigées par un LLM si une clé API est fournie. Les résultats sont présentés dans une interface React avec radar, barres de score et plan d’actions.
